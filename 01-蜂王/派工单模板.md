# 派工单模板

> 蜂王下发任务给工蜂，**必须**用这张单，不许嘴上派活。
> 用法：复制到 `03-任务档案/{日期}-{任务名}/00-任务图.md` 的任务表下方，一个节点一张。

## 单张三件套：目标 / 产出 / 验收

```markdown
### 工单 T{n} · 派给：{工蜂名}

**目标**（一句话，不许含糊）
> 做什么，做到什么程度。

**输入**（工蜂起步所需的一切）
- 资料/文件路径：
- 前置任务产出：
- 必要背景（不写全不许开工）：

**产出物**
- 路径：`03-任务档案/{日期}-{任务名}/01-工蜂产出/{文件名}`
- 格式/规格：
- 命名规范：`{工单ID}-{产出类型}-{简述}`

> **产出形态路由（写单时必须先判，判错 = 整单退回）**
> | 产出是 | 走哪条产线 | 格式要求 |
> |---|---|---|
> | 标识 / Logo / 图标 / 字标 / 印章 | **矢量精绘** | 必交 SVG 源文件 + 多尺寸透明 PNG + 单色 + 反白；禁走生图 |
> | 氛围图 / 插画 / KV / 配图 / 特效 | AI 生图 | PNG/JPG，标注尺寸与风格 |
> | 文档 / 提案 / 表格 | 筑巢蜂产线 | 走 tencent-docx / pptx / sheetagent 专用技能 |

**验收标准**（可勾选，不许写"做得好一点"）
- [ ] 标准1
- [ ] 标准2
- [ ] 标准3

**边界**（明确不做什么）
- 不做：
- 不碰：

**约束**
- 风险等级：高 / 中 / 低
- 依赖：T{x}
- 并行组：G{y}
- 特殊要求：（如：零水印零 Logo 零文字 / 必须符合某某品牌规范）

**状态**：待办 → 进行中 → 完成 / 阻塞
**阻塞说明**：
```

## 派单自检（蜂王发单之前必查）

| 检查项 | 不通过怎么处理 |
|---|---|
| 目标是否一句话说得清？ | 说不清 = 任务没拆够，重拆 |
| 输入资料是否齐全（含绝对路径）？ | 缺就让工蜂自己猜 = 埋雷，补齐再发 |
| 产出物路径与格式是否明确？ | 不明确，工蜂产物会乱放，必须写明 |
| **产线是否判对**（标识走矢量 / 氛围图走生图）？ | 判错 = 交付物废掉重来，见「产出形态路由」表 |
| 验收标准是否可勾选、可判定？ | "写得好一点"这种虚词一律退回重写 |
| 边界是否划了？ | 不划边界，工蜂会自行发挥跑偏 |
| 工蜂角色能否匹配？ | 匹配不上就拆任务或换蜂，不许硬塞 |

## 命名规范（工蜂产物）

```
01-工蜂产出/
├── T1-资料包-竞品公众号文章.md
├── T3-提案-新中式餐厅品牌PPT.pptx
├── T5-配图-主视觉KV.png
└── T7-审查表-提案合规检查.md
```

格式：`{工单ID}-{产出类型}-{简述}.{扩展名}`
**中间产物也照此命名，不许出现 `v2-final-最终版.py` 之类的东西。**
