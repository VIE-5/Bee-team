### 2.2 叠加冲突（本单第一要务）

同一屏内并存 **3 套页眉页脚**：

```
素材自带页眉(①) ⊕ 册子页眉      → 品牌名出现 2 次
素材自带页脚(⑥) ⊕ 册子页脚      → 英文名出现 2 次
素材左缘小字(⑦) ⊕ 册子左栏导言  → 语义重复且物理压盖
```

实测素材前景宽 1635px（x 142–1777），而册子左栏文字区 x 132–652 → **物理重叠 510px**。

### 2.3 根因

**整张素材当"图"塞进页面** = 把素材自己的版式叠加在册子版式上。
两者都是"完整版面"，必然打架。→ **必须拆解素材、按组件重组**，这是本单的核心判断。

### 8.2 几何预算（本单最大新知）

```
格宽 = (版心 1656 − 栏缝×(n−1)) ÷ n      图高 = 格宽 ÷ 比例
n=3 且 16:9 → 图高仅 290px，占内容区 9.8%
```

**这是数学必然，不是 CSS bug** —— 三图并置在本画幅下永远是「小图 + 大虚空」。
唯一出路是**换布局**而非调 CSS → 采用 2+1 主次版（上排 2 图 800×380 + 下排 1 图居中，
两行合计 878 ≤ 920），图高 290 → **380px**。

### 8.3 三代 bug 终解：`aspect-ratio` 锁图格

「图与图注间 200~311px 巨缝」反复三代：

1. 图格写死 `height:--fh` → 图 contain 只占 450/700，虚空在格内；
2. 改 `flex:1` 撑高 → `--fh` 上界卡住，空间反而堆到图上方；
3. `.asset-cell` 写 `height:100%` → **grid item 百分比高循环依赖，塌成 24px**。

**终解**：`.asset-row[data-fit="fill"] .asset-fig{ aspect-ratio:var(--ar) }`
→ 图格高恒等于图真实高，虚空从源头消失（探针验证 `fig == img` 全对齐）。
