# 03 · 交付规格｜抖音竖版（1080×1920）

> 依据 `01-品牌锁定-BrandLock-v2.md`。**本规格是生产合同**：生图通道只负责"无字画面"，中文与 Logo 一律**确定性合成**。
> 定版日期：2026-09-19（含一次版面返工，见第五节）

---

## 一、画幅与安全区（硬规格）

| 项 | 数值 | 说明 |
|---|---|---|
| 画布 | **1080 × 1920 px**（9:16） | 抖音竖版满屏 |
| 顶部遮挡区 | y **0–130** | 抖音顶部 UI → **不放任何信息** |
| 底部遮挡区 | y **1440–1920** | 昵称/文案/音乐条/按钮 → **不放任何信息，允许被裁切** |
| **信息安全带** | **y 130–1440** | 全部文字、Logo 必须落在此区间 |
| 版心 | 左右各 **64 px** | 文字块不越 `x 64–1016` |

## 二、版式定式（自上而下 · 已实拍验证）

| 层 | 位置（实测） | 内容 | 规格 |
|---|---|---|---|
| 1 | y 0–1402 | **无字画面**满幅 | 源图裁掉底部后等比铺满；画面内禁文字、禁 Logo |
| 2 | y 1402–1920 | 岩米 `#E7DCC7` 实色 | 覆盖底部遮挡区，**同时物理盖掉生成水印** |
| 3 | Logo | 墨迹 x 399–679（宽 **280**）、y 204–461 | 官方 PNG 直接贴，**净空框顶 y=140 > 130** ✓ |
| 4 | 副标 | y **528** | 「岭南雅院 · 山野鲜宴」思源宋体 32px，松柏绿 `#58685A`，字距放开 |
| 5 | 主口号 | y **610 / 714 / 818**（三行三字） | 来土蚝／吃生蚝／做土豪，**思源黑体 Heavy 100px**，墨色 `#2D301B` |
| 6 | 产品 | y ≈ 880–1400 | **必须完整可见**，任何文字不得压在产品上 |

> 🔴 **铁律（本轮踩出来的）**：**不得用实色文字带横盖画面中下段**。
> 第一版按"文字带 y 830–1440"做，结果把生蚝与砂锅整段盖掉 —— 餐厅 KV 没有菜＝废稿。
> **正确解法**：文字直接落在画面自带的浅色留白（墙面）上；若画面无留白，则改为"上图下字"分区版式。

## 三、水印处理（生图通道必然带水印）

实测：该通道产出图右下角带「AI生成 / WORKBUDDY」水印，**prompt 无法关闭**。

| 步骤 | 做法 |
|---|---|
| 1 | 先量：扫描源图右下象限近中性亮像素 → 实测水印位于 **x 904–1012、y 1476–1525**（1024×1536 源图） |
| 2 | 再切：**源图裁到 y=1330**（水印上沿 1476 之下已无内容）→ 水印被物理切除，不靠覆盖 |
| 3 | 后验：成品右下象限再扫一次近中性亮像素 → 只剩墙面与蒸汽（无块状水印） |

## 四、生成 → 合成 管线

```
① 生图通道出「无字画面」1024×1536（2:3）
② 裁掉底部（去水印）→ 等比缩放到宽 1080
③ 实色岩米补足 1402–1920（= 底部遮挡区）
④ 确定性排版：贴官方 Logo（按墨迹 bbox 定位 + 25% 净空）
   + 副标 + 主口号三行 + 色值全部取自 Brand Lock
⑤ 出 1080×1920 PNG
⑥ G3 验收 + 像素核对（净空、安全带、水印残留、产品可见度）
```

脚本：`06-成品/compose_kv_v2.py`（含水印定位与产物自检）；局部放大核查：`06-成品/inspect_crops.py`

## 五、像素级自检项（每次出图必跑）

| 检查 | 判据 | 本轮结果 |
|---|---|---|
| Logo 净空框是否越顶 | 净空框顶 y ≥ 130 | y=140 ✓ |
| Logo 墨迹尺寸 | 宽 280、位置居中 x=540 | x 399–679 ✓ |
| 水印残留 | 右下象限无块状亮像素 | 已物理切除 ✓ |
| 产品可见度 | 产品带色彩种类 > 40（非纯色） | 1428 ✓ |
| 文字是否越安全带 | 全部文字 y < 1440 | 最低 818+36=854 ✓ |
| 主口号文字 | 逐字一致，两个逗号、无句号 | ✓ |

## 六、跨画幅一致性检查（出横版时逐条过）

1. Logo 版本/比例/净空与官方文件一致；
2. 画面内红色统一 `#A34435`（Logo 自带红除外）；
3. 主色 `#58685A`、基底 `#E7DCC7` 偏差 ΔRGB ≤ 10；
4. 主口号逐字一致；
5. 信息全部落在各平台安全带内；
6. 零文字残留、零水印、零伪 Logo；
7. 横竖版同一母题（竹影走向、墙面留白、印章语言一致），**横版必须重新构图生成，禁止裁切竖版**。
