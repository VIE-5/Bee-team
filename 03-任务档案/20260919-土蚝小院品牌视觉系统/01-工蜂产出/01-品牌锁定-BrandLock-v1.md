## 2. Logo 锁定

**构成**：拱形门洞 + 起翘瓦檐 + 垂挂宫灯（墨绿）＋ 毛笔书法「土蚝小院」＋ 左下朱砂方印「土蚝」＋ 底部两枚椭圆卵石（落款感）。

| 项 | 实测结果 | 标签 |
|---|---|---|
| 文件规格 | 1671×941 px · RGBA 透明底 · 墨迹占比 9.25% | 实测 |
| **官方墨色** | **#2D301B**（实心像素色簇高度集中 #2C2F1B~#2F311C → 纯平涂、零渐变） | 实测 |
| **印章红** | **#DE1C19** 一带（实心像素众数 #DE1C19 / #E21D19 / #E31D19） | 实测 |
| 墨迹包围盒 | x 449~1233、y 80~799 → 墨迹 785×720，宽高比 **1.09** | 实测 |
| 源文件边距 | 左 449 / 右 437 / 上 80 / 下 141（下留白最窄，底部卵石贴得近） | 实测 |
| 冷色异常排查 | 无（0 个蓝移像素，无水印冷色残留） | 实测 |

**Logo 变体**：仅允许「深底反白稿」与「单色稿」两种，且必须用**双色互换**算法从官方文件生成（暗部→白、亮部→本版主色，alpha 原样保留）。
⛔ **绝对禁止**把 Logo 交给生成模型重绘、描摹、改字、加描边/阴影/渐变。
**净空建议**：四周留白 ≥ 墨迹高度 720 的 25% ≈ **180px（源尺寸等比）**；底部可再放大到 200px，给"落款"呼吸。

## 5. 视觉轴与形态规则（本次已定，供三方向共用）

- **克制度**：偏克制（留白、细线、低饱和，不做满版浓彩）
- **几何—有机**：双轨并存 —— 月洞门＝几何轨道｜山水竹影＝有机轨道
- **熟悉—实验**：偏熟悉（东方庭院人人能读，不玩抽象实验）
- **圆**：月洞门是画面中唯一的"完整圆"；其余弧线取蚝壳同心纹（**不闭合**）
- **线**：墨绿细线，不用粗描边；按最终尺寸保证 **≥1.5px 可辨**
- **留白**：画面留白 **≥45%**；主体重心在下方 1/3
- **材质**：纸（哑面微纹理）、木（胡桃色）、陶/砂器、竹
- **构图**：跨画幅时**重构层级**（横版重排图文、竖版重排前后景），禁止拉伸裁切

## 8. 已知限制（必须随交付物一起说明）

1. **无矢量 Logo 源文件** → 不能声称"印刷就绪 / 可无损放大 / 商标可用文件"；大幅门头灯箱、单色丝印、烫金工艺需要 AI/EPS/SVG 矢量源。**建议主人补源文件。**
2. **生成通道未就绪** → 本会话尚未连接可灵连接器；锚点图的付费生成需先解决通道（可连接连接器，或降级用宿主内置生成，但降级只出**栅格图**，且不承担确定性合成能力）。
3. **中文与 Logo 不生成** → 物料中的中文与标识一律后期贴图 / 人工排版，模型只负责"无字画面"。
4. **受众画像缺失** → 三方向中的"受众欲望"为推断，待主人一句话校准。
