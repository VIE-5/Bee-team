> 🔴 **横版铁律（本轮踩出来的）**
> ① **左栏必须是独立图层再整体贴回画布** —— 否则 Logo PNG 的透明边缘可能污染照片区。
> ② **照片裁切先保"最右产品完整"**：首版裁到 x=1346 时，最右侧那枚生蚝的碗沿被切掉约 19px；
>    实测"最右侧近中性亮像素 max x = 1339"后放宽到 **x=1380**，产品完整且水印（源 x1415 起）仍在刀口之外。
> ③ 缩略图会把"产品被切边"看成正常出血 —— **必须量像素**，不能目视。

## 三、水印处理（本轮的关键教训）

水印压在**虚化暗带**上（半透明）→ **亮度阈值法失效**：

| 尝试 | 结果 |
|---|---|
| `min(channel) > 205 且 range < 18` 全画扫 | 未检出（水印半透明，叠暗带后到不了阈值） |
| 放宽到 `> 150 / < 25` | ❌ 大片**假阳性**：亮墙高光越阈，扫出 3789 像素、bbox 覆盖大半个画面 |
| **几何切除 + 废弃条带反证** | ✅ 正向：废弃条带（源 x1346–1536）扫出 bbox **`[1415,963]–[1525,1013]`** → 水印确在此带；反向：保留区 20×20 块高密度近白中性块 = 0 |

**结论**：水印检测首选「几何切除 + 双向反证」，阈值扫描只当辅助，且必须在**已知水印所在的小窗口内**用。

## 四、生成 → 合成 管线

```
① 生图通道出「无字横构图」1536×1024（3:2 · prompt 内明写 left third 留空作文字位）
② 量测：最右产品像素边界 / 右侧暗带起点 / 水印 bbox
③ 裁切 (20,0,1380,1024) → 等比铺满 1434×1080
④ 左栏独立图层：贴官方 Logo（墨迹 bbox + 25% 净空）+ 副标 + 主口号三行 + 规线 + 英文
⑤ 出 1920×1080 PNG
⑥ 自检 + 1:1 局部核查
```

脚本：`06-成品/compose_kv_h.py`（含双向水印复核 / 产品边界 / 底色精确性）；1:1 核查：`06-成品/inspect_h.py`
