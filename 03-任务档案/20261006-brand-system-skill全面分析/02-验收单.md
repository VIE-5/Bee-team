1. **Brand Lock 三权分立** —— 参考素材 / 品牌锚点 / 产品包装 分权控制，禁越界 → **填补蜂群空白**

3. **Generation Plan 强制门** —— 每次生成前出计划并获批 → 与主人"先 spec 后执行"同频
4. **PRESERVE 字段** —— 修正时明确"什么不许动" → 守卫蜂目前缺此项

**两个跨项目印证**：
