## 三、重生成方式（已核对脚本用法）

不入库的 PDF 全部可由同任务的 HTML 源重出。脚本 `_中间文件/export-pdf.py` 签名：`export-pdf.py <index.html> <out.pdf> [期望页数]`

```bash
cd "03-任务档案/20260921-土蚝小院品牌全案封装"
python _中间文件/export-pdf.py 01-工蜂产出/index.html 01-工蜂产出/土蚝小院-品牌视觉全案.pdf 60
```

脚本内部固定使用 `--force-device-scale-factor=2`（等效 192dpi）与 `--no-pdf-header-footer`，并在收尾核对页数、MediaBox 与体积。

> **注**：重出后的 PDF 体积预计仍在 90MB 量级（v5 45 页即 90.68 MiB），**依旧高于 50MB 阈值**，因此仍不入库——本清单即为其唯一登记入口。
