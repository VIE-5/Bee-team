# 任务档案

> 每单任务一个目录，**永不删除**。这是蜂群的黑匣子，也是复盘的唯一依据。

## 目录命名

```
03-任务档案/{YYYYMMDD}-{任务名}/
```

例：`20260911-土蚝院子视觉解构提案/`

## 三件套（缺一不可）

| 文件 | 谁写 | 什么时候写 | 内容 |
|---|---|---|---|
| `00-任务图.md` | 蜂王 | 开工前写好，过程中持续更新 | 指令原文 / 理解复述 / 假设清单 / 成功标准 / DAG 任务表 / 执行日志 |
| `01-工蜂产出/` | 各工蜂 | 边干边落盘 | 所有中间稿与成品，按 `{工单ID}-{类型}-{简述}` 命名 |
| `02-验收单.md` | 蜂王 | G3 验收之后 | 六项打分 / 返工记录 / 遗留问题 / 学习项 |

## 一单结束的四个标志

1. 所有工单状态为「完成」（无阻塞未处理）
2. `02-验收单.md` 已落盘，评级 A（或 B 且已返工通过）
3. 已按 `00-蜂巢规范/蜂巢Git工作流.md` 提交（message 以 `task:` 开头）
4. 有值得记的东西写进了 `04-知识沉淀/`

**四条全绿才算收工。** 缺任何一条，蜂王不许喊"做完了"。
