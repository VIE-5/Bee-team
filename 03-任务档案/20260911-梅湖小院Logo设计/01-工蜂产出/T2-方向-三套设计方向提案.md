# 梅湖小院 · 三套 Logo 设计方向提案

> 工单：T2 · 主责：W2 提案筑巢蜂 · 依据：T1 品牌策略分析 · 日期：2026-09-11

**策略约束回顾**：雅而不贵 · 鲜而有烟火 ｜ 三条禁区：忌高冷、忌繁复、忌撞脸

---

## 方向 A ·「湖月映梅」— 圆形徽章式

| 项 | 内容 |
|---|---|
| **设计理念** | 把"湖"与"梅"压进一枚印章里。外圈是层层水波，内里是梅花与月影合一——月是圆的，梅是散的，一动一静，正是院子里抬头看到的景。 |
| **核心符号** | 圆形徽章 · 水波纹外环 + 五瓣梅 + 月轮廓 |
| **构成手法** | 对称中心构图，外环留 8-10% 呼吸位；梅瓣做几何化处理，不写实 |
| **配色** | 墨绿 `#1F3A2E`（主）· 米白 `#F3EDE0`（底）· 胭脂红 `#A8322D`（点缀，仅用在花心） |
| **字体建议** | 思源宋体（Source Han Serif，开源可商用）——端正、有书卷气，与徽章气质匹配 |
| **应用场景** | 门头招牌、印章、餐具底标、菜单封面 |
| **气质** | 传统 · 沉稳 · 有院子感 |
| **风险自评** | ⚠️ 圆形徽章是餐饮 logo 重灾区，撞脸概率高。差异化必须落在"梅与月融合"这个点上，绝不能只是"花 + 圆框" |

## 方向 B ·「院门鱼跃」— 几何负空间式

| 项 | 内容 |
|---|---|
| **设计理念** | 一扇月洞门，门里跃出一条鱼。用最少的线讲完"院子里吃鱼"这件事——门是院，鱼是招牌，负空间是留白。 |
| **核心符号** | 月洞门（圆拱）× 鱼形负空间 |
| **构成手法** | 单线几何，鱼身由门洞的负形构成（正负形互换）；线条等宽，无渐变无阴影 |
| **配色** | 石青 `#2C4A52`（主）· 竹青 `#7A9A6B`（辅）· 暖白 `#FAF6EE`（底）· 可用单色呈现 |
| **字体建议** | 思源黑体 Light（开源可商用）——几何感与图形同源，现代而不冷 |
| **应用场景** | 门头、外卖包装、小程序图标、菜品贴纸 |
| **气质** | 现代新中式 · 克制 · 有呼吸感 |
| **风险自评** | ✅ 负空间手法辨识度最高，缩到 32px 仍可辨；⚠️ 要求线条极精准，若生成走形会立刻显得业余 |

## 方向 C ·「梅湖墨韵」— 笔意图形化

| 项 | 内容 |
|---|---|
| **设计理念** | 取书法里"湖"字三点水的笔势，让它长成一条鱼的尾巴；一枝梅从鱼背斜出。有墨、有鱼、有水，还有一点手作的烟火气。 |
| **核心符号** | 笔意水纹（鱼尾）× 梅枝 × 鱼身 |
| **构成手法** | 自由形，飞白笔触；笔锋处保留枯笔细节，但整体轮廓收干净 |
| **配色** | 玄墨 `#1A1A1A`（主）· 朱砂 `#B93A32`（印章点缀）· 宣纸米 `#EFE7D8`（底） |
| **字体建议** | 霞鹜文楷（LXGW WenKai，开源可商用）——手写楷意，与笔触同调 |
| **应用场景** | 主视觉 KV、文化墙、伴手礼包装 |
| **气质** | 文化感强 · 手作 · 有温度 |
| **风险自评** | ⚠️ 笔触细节多，缩小后易糊（需额外出简化版）；⚠️ 墨色重，若不加暖色会滑向"高冷"，触碰策略禁区 |

## 三方向对比速查

| 维度 | A 湖月映梅 | B 院门鱼跃 | C 梅湖墨韵 |
|---|---|---|---|
| 风格坐标 | 传统徽章 | 现代几何 | 文化笔意 |
| 撞脸风险 | 高 | **低** | 中 |
| 缩放下限 | 64px | **32px** | 128px（需简化版） |
| 与人均 60 的匹配 | 中（偏贵气） | **高**（克制不冷） | 中（偏文气） |
| 延展性（包装/周边） | 强 | **强** | 中 |
| 差异化支点 | 梅月融合 | 负空间鱼形 | 笔意水纹 |

**推荐优先级**：B > A > C。理由：B 最不容易撞脸、最小尺寸可用性最好、气质与"人均 60 的雅而不贵"最贴合；A 作为稳妥的传统备选；C 气质最好但落地成本最高（需要人工修笔触）。

## ⚠️ 关于"文字"的工程说明（给主人）

**AI 生图模型对中文字形几乎无法正确输出**（会出现伪汉字、错笔、缺笔）。因此 T3 的交付策略是：

1. **只交付图形标**（零文字，也符合蜂群"零水印零文字"铁律）
2. 品牌名"梅湖小院"的排版，在交付说明里给出**字体 + 字距 + 组合规范**建议，由主人后期用设计软件排定
3. 这样交付的图形可 100% 用于后期延展，且不会被 AI 的错字污染

如需"图形 + 文字"的完整锁定版，建议在图形选定后，由人工排字（10 分钟的事），不宜交给模型。
