## 一、结论

**主人指出 V1 三版"未达餐饮 logo 标准、更像辅助图案与软布灯箱效果"——蜂王复核后确认：三条全部成立。**

根因不是 prompt 不够好，而是**工具选错了**：AI 生图产出的是"渲染插画"，天然带渐变、柔光、场景感，而餐饮 logo 的标准是**纯平涂、零渐变、几何精准、缩小可辨、可单色**。

因此 V2 **更换兵器**：W3 图片施工蜂从「AI 生图」切换到「**矢量精绘（手写 SVG 路径）**」，100% 可控，重新交付 3 版。

## 二、V1 为什么不合格（复核结论）

| 版本 | 主人反馈 | 蜂王复核的病灶 |
|---|---|---|
| A 湖月映梅 | 辅助图案 | 花瓣画成**叶形**、底部叠加波纹装饰 → 纹样感；圆盘有**径向柔光渐变** = 灯箱布效果 |
| B 院门鱼跃 | 辅助图案 / 灯箱 | "门"是两个对称括号 → 可无限重复的**装饰纹样**；鱼形似卫星；背景有柔光渐变 |
| C 梅湖墨韵 | 辅助图案 / 灯箱 | 本质是**水墨插画**不是标识；笔触渲染 + 渐变 = 喷绘布质感 |

**共性病灶**：① 图形不凝练，可被反复平铺 → 图案而非标识；② 有渐变/柔光/笔触渲染 → 场景效果而非标志；③ 缺少 logo 必备的"单一焦点 + 几何精度"。

## 四、三版详解

### 01 ·「梅章」— 传统徽章式

- **理念**：一枚印章。细圆环为界，五瓣梅居中，朱红点为花心。
- **配色**：墨绿 `#1F4E4A` · 胭脂 `#C0392B`
- **适用**：门头招牌、印章、餐具底标、菜单封面
- **气质**：传统 · 端正 · 稳妥
- **最小可用尺寸**：48px（圆环偏细，16-24px 时环线会视觉消失，小尺寸请改用图心）

### 02 ·「鱼跃」— 现代几何式 ⭐ **推荐主推**

- **理念**：一轮月，也是湖面。一条鲤从湖中跃起，腹下一道水波。
- **配色**：石青 `#24505A` · 宣纸米 `#F7F2E7`
- **适用**：门头、外卖包装、小程序图标、菜品贴纸、工服刺绣
- **气质**：现代新中式 · 干净 · 有呼吸感
- **最小可用尺寸**：**32px**（三版中缩放下限最低，延展性最强）
- **主推理由**：撞脸风险最低、单色表现最好、与"人均 60 的雅而不贵"最贴

### 03 ·「鱼印」— 印章负空间式

- **理念**：玄墨方印，鱼形由负空间"挖"出。印章 = 小院的印信，负空间的鱼 = 湖中之鲜。
- **配色**：玄墨 `#23211F`（可单色）
- **适用**：包装封口贴、伴手礼、文化墙、餐具烙印
- **气质**：型格 · 有分量 · 中式当代表达
- **最小可用尺寸**：40px

### 三版对比

| 维度 | 01 梅章 | 02 鱼跃 ⭐ | 03 鱼印 |
|---|---|---|---|
| 构图 | 圆形徽章（空心） | 实心圆 + 负空间 | 方形印章（负空间） |
| 主色 | 墨绿 | 石青 | 玄墨 |
| 缩放下限 | 48px | **32px** | 40px |
| 撞脸风险 | 高 | **低** | 中 |
| 单色表现 | 好 | **极好** | 极好 |
| 气质偏向 | 传统端庄 | 现代克制 | 当代型格 |

| 03 鱼印 | **马善政楷书**（Ma Shan Zheng） | SIL OFL 1.1 | 手写楷意，与印章调和 |

> 三款均**免费可商用**（SIL OFL 1.1），无字体授权风险。字体源：Google Fonts 仓库。
> 交付为**排版完成的高清 PNG**；若你需在 AI / Figma 里二次编排，用同名字体重排即可，字距规范已标注在规范板上。

**组合规范（已落在规范板）**：
- **横式**：图形在左、字标在右；字标高 ≈ 图形高 40%；中文字距 +5%、英文（拼音）字距 +42%
- **竖式**：图形在上、字标在下；中文字距 +10%，居中对齐
- **安全留白**：四周预留 ≥ 图形高度 25%，不得被侵入
- **最小使用尺寸**：横式整体高度 ≥ 40px；竖式整体高度 ≥ 56px
- **禁止项**：不得拉伸变形 / 改色 / 加描边阴影 / 重排字距
