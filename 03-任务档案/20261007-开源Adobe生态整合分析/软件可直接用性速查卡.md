## 二、开源 vs 商业：为什么没有「授权」这一步

| 环节 | Adobe 类商业软件 | 开源软件 |
|---|---|---|
| 安装后激活 | 必须登录账号 + 订阅 | **无此步骤** |
| 序列号 / 许可证文件 | 需要 | **不需要** |
| 联网验证 | 定期校验 | **离线可用** |
| 试用期 | 7 天限制 | **无期限** |
| 功能阉割 | 免费版砍功能 | **全功能** |
| 卸载残留 | 常有 | **干净** |

> **关键认知**：开源许可（GPL/MIT/Apache）是**法律条款**，不是**技术锁**。它规定你能拿代码做什么，但**不在软件里设任何拦截**。

## 三、四个必须先知道的坑

### 坑 1｜Inkscape 首次启动卡顿（正常现象）
首次打开需初始化字体缓存，卡 **5–30 秒**。
→ **不要强杀进程**，等待即可。二次启动正常速度。

### 坑 2｜Inkscape 无 CMYK（⚠ 对印刷交付是硬伤）

| 能力 | Illustrator | Inkscape |
|---|---|---|
| CMYK 原生支持 | ✅ 完整 | ❌ 无 |
| 专色 (Spot Color) | ✅ | ❌ 不支持 |
| ICC 色彩配置 | ✅ | ❌ 不支持 |
| 印刷软打样 | ✅ | ❌ 不支持 |

**影响评估（针对餐饮品牌全案）**：
- ✅ **不影响**：矢量图形本身（SVG 是纯数学路径，色彩模式由印厂端转换）
- ✅ **不影响**：屏幕交付、网页、社媒、PPT 提案
- ❌ **有影响**：需要 CMYK 精确控制的印前文件（画册、包装、印刷物料）

**应对**：SVG 源文件照做；**印前 CMYK 环节交给印厂转换，或保留一条 Illustrator**。

### 坑 3｜Python 工具的环境门槛
rembg / IOPaint 不是双击软件，须先建虚拟环境。
→ 教程第八章已给完整命令，**复制粘贴即可**。

### 坑 4｜首次运行需联网下模型
- rembg 首次：约 **170MB** 模型
- IOPaint 首次：LaMa 模型
→ 之后完全离线。**第一次别断网。**

## 六、常见「以为坏了」的误判

| 现象 | 其实是 | 处理 |
|---|---|---|
| Inkscape 首次启动卡住 | 字体缓存初始化 | 等 5–30 秒 |
| 命令行说命令找不到 | PATH 未生效 | 重开终端，或用绝对路径 |
| rembg 第一次跑很久 | 下载模型 | 正常，等下载完 |
| 导出的图周围有白边 | 未裁剪 | 加 `--export-area-drawing` |
| 图看起来模糊 | DPI 太低 | 加 `-d 300` |
| PowerShell 拒绝运行脚本 | 执行策略 | 加 `-ExecutionPolicy Bypass` |
