## 二、逐个仓库要点（依据各自 README）

### 1. eternity4719/HowToLiveBetter —— 《高性价比人生指南》原著（57,193 ★）

**一句话**：以"性价比"为排序逻辑、只引原始文献与官方文件的循证生活决策库，覆盖健康、金钱、法律、社保、婚育、出国等 34 个主题。

- **内容规模**：**676 条**建议；34 节；A 级证据 439 条、B 级 182 条、C 级 55 条；另标争议 72 条、待核实 3 处；来源含 1,732 条原始文献链接。
- **核心方法论（四个维度）**：
  - **四种资源**：寿命 / 时间与精力 / 金钱 / 人身自由——四者**各算各的，不互相折算**。
  - **证据分级 A/B/C**：A＝有可直接核查的具体数字（荟萃分析、大型队列、RCT）；B＝有研究但无确切数字或仅有单项小样本；C＝作者经验或公论。
  - **性价比档**：由"收益量级（大/中/小）× 口径 × 三项成本（钱/时间/毅力）"合成，分**极高（114 条）/ 高（303 条）/ 一般（259 条）**。作者明示：性价比档是**主观判断、本身只算 C 级**，与证据等级互不影响。
  - **受益人分档**：按"好处回到自己身上的概率"分四级（自己 → 配偶直系亲属 → 朋友同事 → 陌生人），不合并计算。
- **每条的固定结构**：成本 / 说人话 / 收益 / 证据等级 / 来源（期刊论文带 DOI 或官方文件）/ 备注（含争议与适用边界）。
- **使用方式**：在线检索页（按关键词、章节、证据等级、成本三维筛选）、离线单文件 HTML、PDF（A4 两百余页带书签）、EPUB、Anki 牌组——后四样随正文更新自动重建。
- **附带 AI Skill**：仓库内 `skills/life-decision-guide/`，支持 Claude Code 与 Codex，先查书再回答并标注"第几节第几条"，查不到即说明查不到、不编数字。
- **编写方式（透明度高）**：在 Claude Code 协助下查找原始文献、逐条核对数字、维护交叉引用与构建脚本；选题取舍与最终审定由作者负责。
- **重要声明**：**作者从未、也不会发行任何代币或数字资产**，借本项目名义发的币均为骗局。
- **生态**：官方授权的多语言翻译（英/俄/西/葡/越南语）、社区维护小程序版、iOS App、结构化数据集、镜像站等。

### 2. cdyforever/how-to-live-better —— 单文件在线阅读页（10,635 ★）

**一句话**：把原书正文渲染成"一个自包含 HTML 文件"的手机可读阅读器，功能单一、体验完整。

- **定位**：**不是 fork**，不改动原书内容，只做渲染；正文以原书为准。
- **技术特点**：**零外部资源**——无 CDN、无字体外链、不 fetch 数据，**断网可读**；双击 `index.html` 即用，无需构建。
- **页面功能**：逐条卡片（标题 + 证据等级 + 性价比档 + 成本标签）；原书"说人话"栏做成最显眼的高亮块；全文搜索并高亮、只看 A 级、只看说人话；左侧目录带性价比色点并滚动联动；手机端搜索框独占一行、顶栏自动收起；明暗主题切换；支持打印。
- **自动化**：GitHub Actions 每天 06:00（北京时间）拉取上游重建，内容变化才提交；统计口径与上游徽章逐项对齐。
- **构建**：`python build.py all -o index.html --repo <上游本地克隆>`。
- **许可**：原书正文为 CC BY 4.0，构建脚本不作权利保留。
- **版本快照**：README 标注全书 **528 条 / 32 节**（滞后于上游当前 676 条 / 34 节，属快照时差）。

### 3. Chami537/life-development-skill —— "人生发展" AI 答疑技能（160 ★）

**一句话**：把原书的判断方法封装成对话式 AI 技能，**结合个人真实处境**做选择比较并给出下一步。

- **形态**：支持 `SKILL.md` 的智能助手（示例以 Codex 安装），显示名"人生发展"，调用名 `life-development`。
- **答疑四步法**：① 理解处境（区分事实/感受/推测，只补问影响判断的信息）→ ② 按需找依据（读完整条目，含备注、适用条件、争议）→ ③ 比较可行路径（成本、收益、风险、退出条件、不行动的代价）→ ④ 给出下一步（1~3 个具体动作，不确定时优先设计"能退出的小尝试"）。
- **边界克制**：对方只想倾诉时不强行做人生规划；否定某做法时尽量给原本合理的需求提供替代路径；不代替诊断/处方/专业法律意见；不明文把收益折算成单一分数。
- **与上游关系**：**非官方**。上游后来自己也出了 `life-decision-guide` 技能；本项目保留"结合个人处境的对话方法 + 离线资料快照"，未替换上游的排序与固定输出格式。
- **数据快照**：快照日期 2026-10-04，上游提交 `b4048d1`，同步 43 个上游提交、净增约 27 条；随仓库**人工更新，不自动追踪上游**。
- **文件结构**：`SKILL.md` + `agents/openai.yaml` + `references/`（topics / evidence / guide 含 34 章 657 条正文、8 篇长文、120 份核实记录）。
- **诚实标注**：明确区分"指南记载 / 当前核实的事实 / 基于处境的推断"；标注部分条目（如 F-1 留学政策）核实时点早于快照日期，不可把快照日期当作政策核实日期。
