## 二、碗香领先的三项（实测）

### 2.1 内容覆盖更完整：1.25 页/素材 vs 1.67 页/素材
碗香 44 张素材全部入册、无并置、无一图多页；土蚝 24 张素材撑 40 页，靠 duo/trio 并置 + 10 页留白页填量。
按主人铁律「一物料一页」，碗香的密度取向是对的——**并把 7 张 Moodboard 也当作可展示资产收进册子**（土蚝无对应类别）。

### 2.2 验收强度高一个档
| 手段 | 土蚝 | 碗香 |
|---|---|---|
| 独立验收方 | 是 | 是 |
| 首轮是否打回 | 否 | **是（C 打回，2 高 + 2 中 + 4 低）** |
| 根因级实验 | 无 | ✅ **最小复现**定责 MediaBox 偏差 |
| 像素级回归 | 无 | ✅ 17 页全同 / 27 页亚像素 / 11 页差异选址验证 |
| 交付件本体取证 | 无（验的是 PNG 与 `index.pdf`） | ✅ **PDF 文本层全册页眉计数 + 逐页编号配对** |

### 2.3 ★ 交付件版本一致性 —— 标杆在这里失守，碗香已修
**实测证据（逐页比对两个 PDF 的渲染像素）：**

| 项 | `土蚝小院-品牌视觉资产全案.pdf` | `index.pdf` |
|---|---|---|
| mtime | **13:37:29** | 14:35:47 |
| 体积 | 57.0 MB | 57.4 MB |
| md5 | `1c8100018c…` | `0fa3dd8bc2…` |
| 内容不同页 | **14 / 40**（P7、P9、P12–14、P17–18、P26、P29–31、P35–36、P38） | — |

- `index.html` 的 mtime 是 **14:33:50**，`theme.css` 是 **14:25:46** —— **交付件早于源 56 分钟**。
- 差异内容不是噪声：P12 缺「黑稿 / 反白稿 / 灰度稿」整页，P13/P14 标志规范页未重排，P17/18/26/29/30/31/35/36/38 的页脚内容类型标记未改为字距展开写法（`CULTURE WALL` → `C U L T U R E W A L L`）。

**判定**：标杆的**交付名文件是更早一版的构建残留**，且从未被发现——因为当轮验收看的是 PNG 与 `index.pdf`，**没有对「交付名文件」本身做取证**。这正是碗香首轮守卫蜂抓出的高severity 2「PDF 与源脱钩」的同一失效模式。碗香本轮已用 `--pdfname`（一次落交付名）+ 时序校验 + PDF 本体取证把它焊死。

## 三、碗香落后标杆的五项（按影响排序）

### 3.1 页眉/页脚贯通度（形式差最大）
- 土蚝：`.hd` 40/40、`.ft` 40/40 —— **页眉页脚全册无断点**，页脚三栏（英文全名 / 内容类型标记 / 页码 `NN / 40`）。
- 碗香：`.hd` 46/55。**封面、7 张章节页、尾页共 9 页无页眉**；**全册无页脚、无页码**。
- 这带来两个实际后果：
  1. **深绿章节页与米白内容页交替时，视觉上「断」了**——土蚝靠贯通的 `hd/ft` 把满幅图版页也缝进同一节奏。
  2. **客户无法定位页码**——55 页的册子在评审会上无法说「翻到第 37 页」。
- 注：`VI-Proposal-Master` 母版规范写明「不设页码」，故此项**需主人裁决**（见 §六）。但「内容类型标记」不属页码，可直接补。

### 3.2 页型家族窄（叙事手段少）
| 页型 | 土蚝 | 碗香 |
|---|---|---|
| 满幅图版 `bleed`（图占画布 100%） | ✅ 3 页（Slogan / KV 山水 / 灯箱） | ❌ **无** |
| 双图并置 `duo` | ✅ 8 页 | ❌ 无（主人铁律排除，合理） |
| 三图并置 `trio` | ✅ 4 页 | ❌ 无（同上） |
| 留白叙事页 `verse` | ✅ 5 页 | ❌ 无（`preface` 为信息表格式） |

**真正构成缺陷的只有 `bleed`**：碗香的 `.plate .shot img` 硬限 `max-width:1040px; max-height:628px`，即图片**永远落在页眉带以下的内容框内**，画布顶端的 15% 页眉带 + 11% 左右边距永远是底色。于是**主视觉 / Slogan 这类"该满幅"的页面，与一张筷套的呈现面积完全同级** —— 缺了视觉上的重音。

量化：碗香图片上限面积 = 1040×628 = 653,120 px²，占画布 1,156,000 px² 的 **56.5%**；土蚝 `bleed` 页 = **100%**。碗香的 `plate` 上限反而占内容框的 89.4%（土蚝 71.9%），**说明碗香不是"图小"，而是"没有一种页型允许图突破内容框"**。

### 3.3 序章铺垫薄（叙事节奏差）
- 土蚝：P1–P8 共 **8 页**——封面 → 目录 → 序言 → 一句话定位 → 品牌人格 → 视觉基调 → 品牌精神 → 章扉。**每页只给一句**，形成呼吸节奏。
- 碗香：P1–P3 共 **3 页**——封面 → 品牌速览（9 行表格 + 1 段说明）→ 目录，随即进入章节。
- 更关键的是**素材用法**：碗香的 7 张 Moodboard（`cat: board`）被平铺进「品牌基础」章节当素材页；土蚝则把同性质的品牌内涵内容做成 5 张 `verse` 叙事页。
  同一个"品牌人格 / 视觉基调"命题，**碗香是"展示素材"，土蚝是"讲述主张"**。

### 3.4 工程结构（可维护性差一代）
| 项 | 土蚝 | 碗香 |
|---|---|---|
| build 架构 | **组件化页型库**：`cover_page / verse_page / chap_page / plate / bleed / duo / trio / end_page` + `zone / split / asset_cell / asset_row / note_list` | **单体内联**：仅 `hd()` 一个函数，其余全是字符串拼接 |
| 颜色决策 | `bc()` 4 态 + `side_cls()` 2 态，**两套判据独立**（有踩坑注释说明为何不能合并） | 无 |
| 几何 token | `--cy0 / --cyh / --bar` 内容区边界显式化 | `top:var(--hdr); bottom:4%`（`4%` 为裸魔数） |
| 间距刻度 | `--s1..--s6` 六档 | **无** |

后果：碗香若要「加一段 / 换一张图 / 调一类页」，须改 build.py 内联字符串；土蚝只需改数据表 + 调页型参数。**土蚝的 `build.py` 之所以是 581 行，不是因为它更复杂，而是因为它把复杂性封进了函数；碗香 129 行看似精简，实为"未抽象"。**

### 3.5 规范收口（与首轮验收单第 6 条同源）
碗香 CSS 现存：
- **5 个死选择器**（HTML 命中 0）：`.t-h1 / .t-h2 / .t-h3 / .t-cap`（母版库遗留）+ `.slide.dark .hd .hr`（**没有任何一页带 `dark` 类**）
- **12 处裸 `gap`**（22 / 24 / 34 / 56 / 20 / 14 / 16 / 12 / 8 / 10 px 等）
- **82 处裸 `px` 数字**
- **无亮度自适应机制**——`grep -i "luma|dark-text|brightness"` 命中 **0**

土蚝对应的三项全部具备。行高刻度碗香已在复核轮补齐（`--lh-*` 七档四族，字面量归零），**间距刻度与亮度机制未补**。

## 四、必须澄清：哪些差异是"需求"，不是"质量"

对标最忌讳把需求差异判成缺陷。以下四项**不构成碗香的落后**：

| # | 差异 | 判据 |
|---|---|---|
| 1 | 16:10 vs 16:9 | 主人拍板「16:10 · VI 母版」；土蚝是 16:9。母版选择不同，非优劣。 |
| 2 | 无 `duo` / `trio` 并置 | 主人铁律「多物料入册默认一物料一页」**明确排除并置**。土蚝的并置是其当轮 brief「视觉为主」的产物。 |
| 3 | 页眉单栏 vs 三栏 | 主人明确要求「**仅呈现一处页眉**」并拍板方案 A 徽章式。土蚝三栏页眉是其 brief「页眉页脚展示细节」的产物。**碗香在此项是「按更严约束交付」，不是「做得更少」。** |
| 4 | 无页码 | `VI-Proposal-Master` 母版规范明示「不设页码」。 |

**结论**：§三 的 5 项里，真正可动的只有 **3.2 的 `bleed` 页型、3.3 的序章铺垫、3.4 的工程结构、3.5 的规范收口、3.1 的"内容类型标记"**；`duo/trio`、三栏页眉、页码三项须先解母版与铁律的约束才谈。
