## 五、本轮两个工具性踩坑（已回写踩坑库）

### 5.1 `render-deck.py --all` 逐张覆盖触发 safe-delete 护栏

- **现象**：`--all` 跑一半中断，报 `[SAFE_DELETE_BULK_CONFIRM_REQUIRED] {"count":50,"threshold":50,"scope":"turn"}`，退出码非 0，仅渲染到第 42 页。
- **根因**：脚本逐张覆盖时会**先删同名旧图**；旧集 56 张 → 累计删除达 50 次触发护栏。
- **正解**：**重渲染前先把 `png/` 整体改名腾空** —— `mv png _png_r2`（本轮零删除，累计删除 0 次），随后 `--all --sheet` 一次跑通 56/56。
- 已写进 `MEMORY.md` 渲染出口段。

### 5.2 切图边界：判据认「结构元素」不认「底色」

- **现象**：P06 切图连续读偏 3 次。① 目视网格图定 x → ④ 左侧混入、⑤ 缺内容、⑥ 切掉右半；② 改用列剖面定边界 → 仍偏（自检报 ④ 右 0.305、⑤ 左 0.291 右 0.224 脏）。
- **根因**：板背景 `#FBF8F1` 与卡片底 `#F7F1E6` 色差低于阈值，自动边界检测失效；**且在缩览图上目视读坐标必然误判**（把 ② 的右栏起点读成 x600，实际 x898；把 ⑤ 徽章读成 x100，实际 x536）。
- **正解**：**改用红色编号徽章（R>160 & G<90 & B<90）精确定位** —— `find_badges.py` 一次给出 ④ x30..67 / ⑤ x536..569 / ⑥ x920..952 / ⑦ x1295..1328，一次收敛。x 右界取「下一徽章左侧的空列」。
- 附带：⑥ 切图顶部残留标注行尾 → `y0` 从 645 下移到 **651**，自检由「上 0.219 脏」变「上 0.003 洁净」。

## 六、新发现：全册字体 100% Type3（根因已定位 · 待主人拍板）

### 6.1 取证

| 对象 | 非 Type3 字体 |
|---|---|
| 碗香（本册） | **无（100% Type3）** |
| 土蚝 V6（60 页） | Georgia · Georgia-Bold · Arial-BoldMT · ArialMT（Type3 占 95%，即全部中文） |

### 6.2 根因（隔离实验钉死，`_work/font-probe/ft2.py`）

单字体族对照实验（同一段「Latin ABC 1234 ｜ 碗香中文」）：

| 字体族 | PDF 内实际字体 | 本机对应字体文件 |
|---|---|---|
| Noto Serif SC | **Type3** | `NotoSerifSC-VF.ttf` ←**可变字体** |
| Noto Sans SC | **Type3** | `NotoSansSC-VF.ttf` ←**可变字体** |
| STZhongsong / PingFang SC / MS Song | Type3 | 未安装（macOS 字体）→ 系统回退 |
| SimSun | `SimSun` ✔ 真实嵌入 | `simsun.ttc` 静态 |
| Microsoft YaHei | `MicrosoftYaHei` ✔ | `msyh.ttc` 静态 |
| SimHei / KaiTi / FangSong | `SimHei` / `KaiTi` / `FangSong` ✔ | 静态 |
| Georgia / Arial / Times New Roman | `Georgia` / `ArialMT` / `TimesNewRomanPSMT` ✔ | 静态 |

**结论：Chrome headless 打印时，命中「可变字体」或「未安装字体（走系统回退）」→ 只能退化为 Type3 字形程序；命中已安装的静态字体 → 真实嵌入。**

碗香的 `--font-serif` 首项 `"Noto Serif SC"` 与 `--font-sans` 首项 `"Noto Sans SC"` **都命中 VF** → 全册 100% Type3。土蚝 V6 同样用 VF 排中文（故 95% Type3），但西文用 Georgia/Arial 静态字体 → 那一层是真嵌入。

### 6.3 影响与处置选项（**未动册子，登记待拍板**）

Type3 字形轮廓精确、无字体依赖、无授权问题，多数现代 RIP 可正常输出；风险在**部分印厂 preflight 会因「未嵌入字体」报警**。

| 选项 | 做法 | 视觉 delta | 代价 |
|---|---|---|---|
| **A**（推荐） | `@font-face` 指向**静态** Noto Serif SC / Noto Sans SC 文件（OFL，可商用可嵌入） | **≈ 0**（同字族） | 需下载静态字重文件（400/500/600/700 × 2 族）；PDF 体积小幅增长 |
| B | 字体栈改已装静态字（SimSun / 微软雅黑 / 黑体等） | **1.5% 像素差**（实测，即**换字**） | 触及 BrandLock §八 字体规范，须主人确认 |
| C | 保持现状（Type3） | 0 | 印厂 preflight 可能报警 |

> 测量依据：`_work/font-probe/ft3.py` —— 当前栈 vs 显式 SimSun = 1.479% 像素差，vs 微软雅黑 = 1.615%，即**当前渲染既不是 SimSun 也不是雅黑**（是 VF 的 Noto SC 实例）。
