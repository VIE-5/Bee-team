## 完成任务：碗香品牌 VI 提案 · HTML 排版封装（练习单）

**档案位置**：`D:\WORK——Vie\贵州遵义\碗香\品牌VI提案\`
**素材源**：`D:\WORK——Vie\贵州遵义\碗香\`（logo 10 + IP 3 + 灯箱画布 6）

### 做了什么
1. 摸清 19 张素材的内容与比例（3:1 / 3.6:1 / 2.5:1 / 5:7 / 2:4 / 2:5 六种比例）。
2. 写 `png-color-pick.py` 从规范页 **像素采样**取品牌色（不目测估色）。
3. 定「19 页 · 四章」版面：封面/目录 → 标志系统 → 色彩系统 → IP 形象 → 应用延展 → 尾页。
4. 自建 `theme-wanxiang.css`（山香绿 #405C38 / 陶火红 #C6492E / 米汤白 #E8DCC7）。
5. 逐页渲染 PNG 目视验收 → 修 3 轮 → 导出 19 页 16:9 PDF。
6. 归档为**自包含结构**：assets 一并拷入，`../../assets/` 改写为 `assets/`，脱离 skill 目录独立可跑（字节级验证一致）。

### 关键设计判断
- **规范页（B06–B10）本身就是 1920×1080 设计稿 → 满版铺满**，零裁切零缩放；章节标贴右上角安全区（规范页右上恒空）。
- **比例特殊素材一律走 `.img-frame.contain`**：IP 四视角 2.5:1、文化旗 2:5 都完整不裁。
- **自排页承担叙事节奏**（封面/目录/章节/色板/尾页），素材页只做承载 —— 避免 deck 沦为「图片轮播」。

### 踩坑（模板级，任何人用此 skill 都会遇到）
1. **满版页整页塌陷成空白**：`.slide` 自身已是 `position:absolute;inset:0`，我在 `.slide.plate` 又写 `position:relative` 打掉了定位上下文，内层 `absolute` 图片层失去参照 → 高度归零。
2. **封面图溢出画布**：`aspect-ratio` + grid 列宽算出的高度超过版心。画布本就是固定 1920×1080 → **改用固定 px 限高**。
3. **导出 PDF 落成 Letter 白边**：`base.css` 的 `@media print` 只设 `.slide{height:100vh}`，**没有 `@page` 定义**。主题内补 `@page{size:1920px 1080px;margin:0}` → 1440×810pt 精确 16:9。
4. **中文路径下 Chrome 截图静默失败**：`--screenshot` 不自动编码中文路径 → 走 `pathlib.Path.as_uri()`。
5. 归档改路径时 `sed` 在中文 + em-dash 路径下可用，但 bash 环境偶发初始化失败（`dirname: command not found`）→ 命令前必须 `export PATH`。
