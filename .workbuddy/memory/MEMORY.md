## 已确立的制度（改之前先想清楚为什么改）

| 制度 | 内容 |
|---|---|
| 沟通准则 | 蜂王默认**静默执行**，只在「需主人拍板 / 有风险 / 交付或卡死」三种情况出声 |
| 工蜂编制 | W1 资料侦查蜂 / W2 提案筑巢蜂 / W3 图片施工蜂 / W4 守卫蜂 / **W5 设计提词蜂** |
| 翻译层（W5） | **只出设计 prompt / brief，不产出成品**；生图类任务默认链路 **W5 出词 → W3 执行**（标识类不出生图 prompt，转矢量精绘） |
| 派单铁律 | 无派工单不派活，工单必须写全：目标 / 输入 / 产出路径 / 验收标准 / 边界 |
| 验收机制 | G1 进场查工单 → G2 长任务抽检 → G3 出厂六项（完整/准确/格式/合规/可用/一致）；评级 A 放行、B 小修、C 重做 |
| 严格度三档 | 速查 2 项（草稿）/ 标准 4 项（**默认**）/ 严查 6 项+专项（对外交付）；口头即可切换 |
| 归档三件套 | `00-任务图.md` + `01-工蜂产出/` + `02-验收单.md` |
| Git | 单主干 `master`（已推 GitHub 仓库 `VIE-5/Bee-team`，SSH 认证），一单任务 = 一次提交（`task:` 前缀），单文件 > 50MB 不入库；**推送策略：手动触发**——蜂王只本地 commit，主人喊「提交并推送」/ `/commit-push-pr` 才 push |
| 生图硬规矩 | 零水印、零 Logo、零文字（铁律，逐张肉眼确认） |
| 产线路由（W3） | **标识 / Logo / 图标 / 字标 → 矢量精绘（手写 SVG），禁用生图**；氛围图 / 插画 / KV → 生图。判错产线 = 整单退回 |
| Logo 交付四硬指标 | 纯平涂零渐变 · 可单色 · 32px 可辨 · 真矢量可缩放；必交 SVG 源文件 + 多尺寸 PNG + 单色 + 反白 |
| 生图水印坑 | 生图通道默认右下角加「AI生成」水印，prompt/footnote 都关不掉 → 走 `04-知识沉淀/工具/clean_logo.py` 裁切补偿（检测要用「行内最大色差」） |
| 中文字标 | 不给 AI 直出（必出伪字），只出图形标 + 开源字体排版建议由人工排 |
| PPT 产线 | **图片素材 → 排版封装** 走 `html-ppt`（html-ppt-studio，MIT，装在 `~/.workbuddy/skills/html-ppt`）。铁律：`image-*` 版式只承载氛围图/空间照/物料图，**Logo/标识仍必须走 `vector-logo-maker` 矢量精绘** |
| Windows 渲染 | 原版 `render.sh` 是 mac 专用 → 用 `04-知识沉淀/工具/render-win.bat`（出 PNG / PDF）；Chrome headless **必须带 `--user-data-dir`**，否则静默失败；**中文路径下截图不自动编码，须走 `Path.as_uri()`** |
| PPT 导出三坑 | ① 导出 PDF 必须在主题写 `@page{size:1920px 1080px;margin:0}`，否则落 Letter 白边；② 满版页**禁止**给 `.slide` 覆写 `position`（它本身已是 `absolute;inset:0`，改写会让内容层高度归零成空白）；③ 固定画布下用**固定 px 限高**，别用 `aspect-ratio` 算高度（会撑破版心） |
| deck 归档 | 归档要**自包含**：拷 `assets/` 到 deck 旁 + 把 `../../assets/` 改写为 `assets/`，否则脱离 skill 目录即失效 |
