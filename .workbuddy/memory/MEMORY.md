## 内容铁律
- **事实源优先**：物料/规范类交付第一个动作＝通读 BrandLock。标志内部色（墨 `#2D301B`、印章红 `#DE1C19`）**不参与物料色板**。
- **样张零编造**：绝不编造菜名/价格/地址/电话/规格；无源数据一律标「—」并上报。
- **一物料一页**（2026-09-22 定）——篇幅不是成本，单体呈现面积才是价值。
- **产线路由**：标识/Logo/图标/字标 → **矢量精绘（手写 SVG），禁用生图**；氛围图/KV/插画 → 生图。
- **生图三零**：零水印、零 Logo、零文字。
- **反白稿**必须「双色互换」，禁止全涂白；生成后合成深底目视。
- **套模板 ≠ 模板没问题**：复用旧版式要整册重过验收，缺陷回写母版。
- **不自动 commit / push** —— 需主人显式要求。

## 渲染出口（唯一）+ 收尾五步
统一走 `04-知识沉淀/工具/render-deck.py`（渲染 + PDF + 联系表 + 产物核对），不要用 `.bat`。
- Chrome headless 必带 `--user-data-dir` + `--force-device-scale-factor=1`
- **调外部程序一律传 Windows 路径 `C:/...`**（中文/破折号路径会被 Git Bash 跳过转换 → 静默零产出）
- **「退出码 0」≠「任务成功」** → 图版类交付**收尾固定五步**：
  **① 数数量 ② 量规格（尺寸集合须单一）③ 对时间戳（产物晚于所有源）④ 贴合体检 ⑤ 溢出体检**
  - ④ `probe_fit.py <index.html>` → 逐图量「渲染尺寸 vs 容器」→ `CROP`/`DISTORT`/`COLLAPSE`
  - ⑤ `probe_overflow.py <index.html>` → 递归量容器内所有元素 bottom → `OVERFLOW`/`(偏空)`
  - 唯一结论 **PASS / FAIL(n)**；**多条目列表 / 多块栅格页（目录·索引·批次页·规格表）必跑 ⑤**
- **根因同一**：`overflow:hidden` **静默裁掉**超出内容 —— **前四步在两种裁切下全部正常**。
  **「内容是否完整」必须单独量**；工具本身也要**双向验证**（正式产物 PASS + 坏样本 FAIL）。
  实证（2026-09-27 两次）：22 张图被裁 / 目录 10 块只显示 4 块（219% 溢出）—— **四次指标全过、内容却是错的**。
- **尺寸约束禁用百分比**（2026-09-18 铁律，已写进 VI 母版规范 §9）：百分比 `max-height` 的基准是**包含块的 `height` 属性**、非 used value；容器高来自 flex 拉伸 → Chrome 解析为 `none` → 图退回原尺寸被裁。
  ⚠️ **`max-width:100%` 照常生效 → 只有竖版图出事**，极难肉眼发现。**本条已复发过一次**（把已验证的 px 上限"改良"成百分比 → 22 张图被裁）
  → **不得"顺便升级"已被验证正确的实现**；换实现须任务图显式列条 + 配等价机检。
- ⚠️ 命令末端串 `| tail` 会吞掉 Python 段退出码，**截断残局也显示「渲染成功 N/N」**
- 小体积 PNG ≠ 空白页（墨底满幅 20–40KB 正常）；**体积显示值也不能当异常判据**（精度仅 0.1KB），**判据恒为 `md5 唯一数 == 页数`**
- **画幅非 16:9 必传 `--viewport W,H`** + `--ratio`；**交付名走 `--pdfname`**（改名会让交付件与源脱钩）
- **验收必须针对「交付名文件」本体，禁止只验中间产物**（土蚝小院交付名 PDF 与中间产物 14/40 页不符、长期未被发现）
- **重渲染前先 `mv png _png_rN && mkdir png` 腾空**：逐张覆盖会先删同名旧图，≥50 张触发 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` 中途拦停
- **交付前必查「字体嵌入」**：本机 `Noto Serif/Sans SC` 是**可变字体 VF** → 全册 100% Type3（印厂 preflight 会报警）；已装静态字（SimSun/雅黑/SimHei/Georgia）能真嵌入

## 排版铁律 R1–R16（派工必下发全文）
R1 满幅层写死 `height:100%`｜R2 内容容器显式 `left/right:var(--mx)`｜R3 不给 `.slide` 写 `padding:0`｜R4 锁 `@page` 尺寸｜R5 疑难上探针别读 CSS｜R6 小体积 PNG≠空白页｜**R7 固定画布下尺寸硬编码 px**｜R8 print 里补 `overflow:hidden`（否则页数+1）｜R9「看起来不对」也先量｜R10 批量替换脚本收尾双向复核｜R11 量 DOM 前先摘祖先 `transform`｜**R12 页面容器 class 必须独立命名空间 `pg-*`**（撞车→打印端多一页、屏幕端截图全同；print 块对 `.slide` 几何 `!important` 硬化）｜**R13「一对多」登记表键带归属维度**（如 `(篇,节号)`）｜**R14 目录/索引必逐行回验**（错行数/总行数）+ 分片流 `.slide` 的 `top` 须为 `n×画布高`｜**R15 版式一改，浏览器实测尺寸缓存立即作废** —— 必须重跑 `--measure` → `run_measure.py` 再重建，否则「预算用旧高、内容是新高」→ **全册静默溢出**｜**R16 删页/改名/调序 ⇒ 页码基准与署名落点同步重算并回验**：页码三处互锁（`pno` 基准 / `TOTAL` / **目录页自身 `page_no`**，最易漏第三处）；删掉署名页或改名后，CC BY 四件套（作者·作品名·来源·许可）落点数必须 **> 0**（**改书名不得抹掉原著书名**）

高频：`<figure>` 要 `margin:0`（否则网格静默掉列）｜改 CSS 没变化先怀疑 Chrome 缓存｜脚本输出只用 ASCII｜**Georgia 是老式数字，页码必加 `lining-nums`**｜照片补边禁用边缘拉伸 → 用「cover + 高斯模糊」

**页眉页脚**：页眉＝左字标｜1px 短竖线｜中栏目｜右英文（**不画通栏长横线**，全册最大噪音源）带高 10%；页脚＝1px 极淡线 + 左品牌右 `NN / 总`，带高 7%；深底页 `.slide.dark` **只切 CSS 变量**自动反色。
**图版承托**：物料/切图一律入 `.frame`（白底 + 1px 边 + 微投影），**禁止裸贴**；尺寸＝**px 上限 + `fit-content` 贴合图片**（满宽白条包小图＝廉价感）。
**间距/字距建刻度**：`--s1..--s6` / `--lh-*` / `--ls-*`，不许行内硬编码。
