### 第三轮自洽性返工 · 五处（教训按价值排序）
1. 🔴 **资产色与矩阵口径不一致**：反白版/单色米白版的主体色是从**参考反白稿 JPG** 实测的「宣纸米白 `#FDF4E3`」，而该 JPG 已被判定"有损、只作参考、**不作为色值依据**"；P11 对比度矩阵却按"反白主体＝岩石米 `#E7DCC7`"算 → 资产与数字两套口径。
   **正解：变体稿的着色一律取品牌色板色（基底色），不从参考件实测色出发。** 已重写 `prep-assets.py` 并重跑。
2. 🔴 **编造文案**：P15 菜单样张写了「炭火生蚝 88 / 山野时蔬 28 / 老火例汤 38」——BrandLock §6 明令"菜品名、价格必须主人提供，禁止编造"。**正解：改灰色排版占位条 + 图注声明**。样张要体现排版，但不许伪造内容。
3. 🔴 **最小尺寸数字冲突**：规范册写 3px→52mm→取 55mm，实测报告却是 2px→78mm。
   **正解：最细笔画测量要走「双向游程（水平测竖线宽 + 垂直测横线粗）+ alpha>200 剔除抗锯齿过渡带」，取 p10 分位**（全图游程分位数会被抗锯齿噪声拉低：用 alpha>128 单向游程得 p5=2px，用 alpha>200 双向得 p10=2px 才稳）。本单定为 **80mm**。
   ⚠️ 结论：**"更保守/更乐观"的分位数选择会直接改变交付数字，必须在报告里写明取哪个分位、为什么。**
4. **离屏页残留 Markdown 星号**：`**不新造品牌事实**` 未改 `<b>`（前一轮漏改处）。→ 批量改动后**必须双向复核**（数新标记 + 数旧标记）。

### 三代 bug 的终解：`aspect-ratio` 锁图格

「图与图注之间 200~311px 巨缝」反复三代：
1. 图格写死 `height:--fh` → 图 contain 只占 450/700，虚空在格内；
2. 改 `flex:1` 撑高 → `--fh` 上界卡住，空间反而堆到图上方；
3. `.asset-cell` 写 `height:100%` → **grid item 百分比高循环依赖，塌成 24px**。

**终解**：`.asset-row[data-fit="fill"] .asset-fig{ aspect-ratio:var(--ar) }`
→ 图格高恒等于图真实高，虚空从源头消失（探针验证 `fig == img` 全对齐）。
