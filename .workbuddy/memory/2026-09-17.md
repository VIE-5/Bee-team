**本轮踩的两个坑（已写进 MEMORY.md）**：

1. **`.deck` transform 导致 `.slide` 高度塌陷**（致命，10 页近空白）
   - `.deck` 的 `transform:scale()` 使子元素 `bottom:0`/`inset:0` 拉伸解析失效，
     `.slide` 高只有 144px（应 1080px）→ 墨底页只剩顶部一条
   - 解法：满幅层写死 `height:100%`
   - 探针佐证：`force height:1080px → 1080`、`deck transform:none → 1080`

2. **正文压住竖排边款**
   - `.bd` 未设 left/right → 继承 `.slide` 的 padding 96px（< 版心 11%）
   - 解法：`.bd` 显式 `left/right:var(--mx)`；边款外移至 `--mx − 62px`

3. **教训：文件体积≠空白页** —— 墨底满幅页 PNG 只 20–40KB 是正常的，
   别再把「小体积」当成「空白页」误判

**工具经验**：
- Windows 批量渲染改用 **Python 脚本**（pathlib + `as_uri()`），
  比 PowerShell 稳 —— PowerShell 5.1 读 UTF-8 无 BOM 脚本会把中文路径读乱，
  且 `$args` 是保留变量不能赋值
- 渲染/导出后必做**产物核对**：数数量 + 看体积
