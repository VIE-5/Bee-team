### 本轮两个真 bug（同一个根因）+ 一个准确性缺陷
1. **（C 级）页面级 class `toc-p` 与 CSS「目录行」`.toc-p` 撞车** —— 一个根因两个症状：
   - 打印端：目录页 section 吃到 `margin-top:22px` → 整页在分片流里下推 22px → **PDF 44 页 ≠ 43 slide**，P04 整页空白
   - 屏幕端：`.toc-p{display:flex}` 与 `@media screen{.slide{display:none}}` **同特异性、后置胜出** → 目录页**常驻可见** → **43 张截图像同一张**
   - 修：页面级 class 统一 `pg-*` 命名空间 + print 块对 `.slide` 几何 `!important` 硬化
2. **（B 级）目录 11/40 行页码错误** —— `sec_page` 以节号单键登记，而同一节可分属两篇 → 改 `(篇, 节号)` 双键，复验 40/40 全对

### 方法沉淀（重要）
- **先前的误诊已更正**：曾判「`--screenshot` 不套用 `@media screen` 可见性」—— 错。真相是 class 撞车；
  当时的「内联 display」修法只是**碰巧绕开**（内联优先级最高），病根留在打印端，几小时后以另一面貌复发。
  **绕开 ≠ 修好。**
- **12 个「改样式」候选全部无效**（页高 1118/1122、`@page` 1130、`break-inside:avoid`、删页眉页脚空白节点、`body{overflow:hidden}`…）
  → **样式全改不动的 bug，查「选择器命中关系」，不是查「属性值」。**
- **幽灵页溯源三招**（已入踩坑库）：① 逐页注入唯一底色 + PDF 像素扫描定位分裂点 ② 复制/移除/重排实验（不动样式）③ CDP `Emulation.setEmulatedMedia('print')` + `Runtime.evaluate` 量分片流真值（各页 `top` 应为 `n×1123`）
