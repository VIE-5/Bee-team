# 设计提词库

> W5 设计提词蜂的作业兵器。**随使用持续补充。**
>
> 用法：接到提词任务 → 先写「意图锚」 → 照九字段填 → 挂负向铁律 → 自检交付。
> 禁止凭感觉写词，一切按本库结构走。

---

## 一、九字段结构（缺一不许交）

| # | 字段 | 写什么 | 常见错误 |
|---|---|---|---|
| 1 | **Subject 主体** | 画面里到底有什么，最具体那一个 | 写太泛（"一个东西"） |
| 2 | **Scene 动作与场景** | 主体在干什么、在哪、和环境什么关系 | 漏场景 = 模型自己编 |
| 3 | **Style 风格** | **流派 / 参照物 / 年代**（不是形容词） | 写"高级""大气"（空词） |
| 4 | **Composition 构图** | 中心对称 / 三分 / 大留白 / 特写 / 俯拍 | 不写 = 模型默认居中大脸 |
| 5 | **Light 光线** | 光源位置 + 软硬 + 方向 + 冷暖 | 只写"好看的光" |
| 6 | **Color 色彩** | 主色 + 辅色 + 明度对比（**给 HEX 或色名**） | 只写"暖色调" |
| 7 | **Material 材质** | 表面质感：哑光 / 釉面 / 粗糙 / 半透明 / 金属 | 不写 = 塑料感 |
| 8 | **Camera 镜头与画幅** | 焦段 / 视角 / 比例（`9:16` `1:1` `16:9`） | 比例漏写 = 比例失控 |
| 9 | **Negative 负向** | 明确不要什么（见第二节铁律清单） | 每次现想，漏项 |

> **填法口诀**：主体要具体，风格要参照，光线要能画出影子，色彩要可对齐色卡。

## 二、负向铁律清单（固定挂载，不临时想）

### 通用视觉（A 线生图默认全挂）
```
no text, no letters, no words, no numbers, no Chinese characters,
no watermark, no signature, no logo, no mockup, no 3D render,
no drop shadow, no gradient background, no frame, no border
```

### 分场景追加

| 场景 | 追加负向 |
|---|---|
| **品牌 / 餐饮视觉** | `no cluttered decoration, no ornate patterns, no clutter, no busy background` |
| **菜品 / 食物** | `no plastic look, no artificial color, no messy plating, no extra cutlery` |
| **空间 / 室内** | `no people, no distorted perspective, no fisheye, no blurry` |
| **人像** | `no extra fingers, no deformed hands, no asymmetric eyes, no full body if headshot` |
| **矢量 / 图标方向** | `no gradient, no shading, no texture, no render, no sketch lines` |

> ⚠️ **本环境已知坑**：生图通道默认在右下角叠加「AI生成」水印，prompt 里的 `no watermark` 与工具 `footnote` 参数**都管不住**。
> → 提词时**必须同时告知 W3**：出图后走 `04-知识沉淀/工具/clean_logo.py` 裁切补偿。

## 三、空词替换表（提词蜂的照妖镜）

**左列的词不许出现在交付里**，必须换成右列这种"看得见"的写法：

| ❌ 空词 | ✅ 可执行写法 |
|---|---|
| 高级 / 高级感 | `minimalist, matte finish, muted palette, large negative space, single soft light` |
| 大气 | `wide shot, low horizon, expansive sky, symmetrical composition` |
| 有质感 | `visible material grain, raking light, tactile surface, shallow depth of field` |
| 有格调 / 有调性 | 具体到**参照物**：`wabi-sabi aesthetic, Japanese minimalism, 1970s editorial` |
| 温馨 | `warm tungsten light 2700K, wood and linen textures, soft shadows` |
| 高级黑金 | `matte black (#111111) with brushed brass (#B08D57) accents, low-key lighting` |
| 有食欲 | `steam rising, glossy sauce highlights, 45° angle, crisp focus on texture` |
| 新中式 | `Chinese courtyard spatial logic, ink-wash restraint, timber lattice, celadon (#9FB5A1)` |
| 网红 / 打卡感 | 无法执行，**退回重问**：到底指色彩？构图？还是场景元素？ |

> **判定法**：把词念给一个没看过图的人，他能不能**画出来**？不能 = 空词。

## 四、高频模板（直接改）

### 模板 A · 餐饮菜品图
```
[菜品名] on [器皿：matte ceramic plate / cast iron / bamboo steamer],
[state: freshly served, steam rising, sauce glistening],
overhead 90° or 45° angle, close-up on texture,
warm directional light from upper left, 3200K, soft falloff,
[sauce/ingredient] tones dominant with [garnish color] accent,
natural daylight look, shallow depth of field f/2.8, 1:1,
no text, no letters, no watermark, no logo, no mockup, no 3D render
```

### 模板 B · 空间氛围图（餐厅 / 庭院）
```
Interior of [空间：new Chinese courtyard restaurant],
[关键元素：timber lattice screen, stone path, plum branches, paper lanterns],
eye-level wide shot, one-point perspective, generous negative space,
late afternoon side light through window, 4000K, long soft shadows,
[主色 HEX] walls with [辅色 HEX] accents, warm neutral palette,
wood / stone / linen textures, matte surfaces, 16:9,
no people, no text, no watermark, no logo, no distorted perspective
```

### 模板 C · 品牌视觉概念图（情绪板 / 氛围）
```
Mood board flat lay for [品牌名] brand identity,
[symbol objects: plum blossom, ceramic bowl, ink stone, dried ginger flower],
arranged on [background: rice-paper cream #EFE7D8] in loose grid,
top-down 90°, even soft daylight, no hard shadow,
[strategy palette: deep ink green #1F3E4A / celadon / cream],
paper and ceramic and raw linen textures, 1:1,
no text, no letters, no words, no watermark, no signature, no logo
```

### 模板 D · 人像 / 表情包基础形象
```
Head-and-shoulders portrait of [人物描述：semi-realistic 3D stylized character],
[表情 / 动作], facing camera, centered composition, plain [纯色] background,
soft three-point studio lighting, even tone, no harsh shadow,
3D-rendered cartoon style, smooth surfaces, clean edges, 1:1,
no text, no letters, no watermark, no logo, no extra fingers, no deformed hands
```

### 模板 E · 视频（图生视频 / 文生视频）
```
[时长] [运动类型：slow push-in / orbit / steam rising] of [主体],
subtle camera move, stable framing, no cut, no zoom snap,
consistent lighting throughout, [ratio]，[seconds]fps,
no text overlay, no watermark, no logo, no morphing artifacts
```
