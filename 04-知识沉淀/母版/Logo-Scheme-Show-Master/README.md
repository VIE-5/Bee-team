# Logo-Scheme-Show-Master · 标志方案展示母版（5 页）

> 一碗水端平的标志提案册版式。**换素材 → 改数据 → 跑两条命令**即出可编辑 .pptx。

来源：碗香 Logo「一」（14 页全案册后主人改口要的 5 页展示版）确立，
经碗香 Logo「二」（3 版全新素材）第二次验证并修正缺陷后固化。

---

## 一、产出长什么样（5 页）

| 页 | 内容 |
|---|---|
| P1–P3 | **每版详页**：左标志展示台（560×442）+ 右「标志构成」三段释义 + **同页色彩应用**（4 色卡 + 配比条） |
| P4 | **并置总览**：N 版等宽并排 + 编号 / 版名 / 适用场景 |
| P5 | **综合应用**：门头灯箱（反白）/ 外带碗盖（彩稿）/ 餐具烙印（墨稿）/ 员工围裙（反白）/ 名片（彩稿+反白） |

**画布 1360×850（16:10）**，1 px = 9525 EMU，全案母版几何 1:1 直落：
边距 11%（149.6）· 页眉带 15%（127.5）· 版心 1060.8 · 页眉分隔线落页眉带垂直中心。
产物是**真文本 + 真图片 + 真色块**，客户能直接改字换图。

## 二、三步用法

### 第 1 步：加工素材

编辑 `prep-assets.py` 的【配置区】：

```python
SRC   = r'D:\...\Logo\二'            # 放着 N 张标志图的目录
WK    = r'D:\...\_work'
FILES = {'A': '版1_红金复古国潮_透明.png',
         'B': '版2_深绿米黄乡土_透明.png',
         'C': 'ChatGPT Image ....png'}   # 白底不透明也行，脚本自动去背
PRIM  = {'A': (0x8A,0x0F,0x0D), ...}     # 各版主色 RGB，反白稿用
```

```bash
python prep-assets.py
```

产出 `_work/assets/trim/logo-{A,B,C}{,-gray,-mono,-reverse}.png`（**已裁透明边**）
+ `_palette.json`（每版真实用色聚类）+ `check.png`（**必看**：左白底 / 中深底 / 右反白深底）。

**色值判读**：看 `_palette.json` 里占比最高的 3~4 个色，按「面积最大 + 角色」定主色/辅色/底色/点缀，
比例如 `56/22/14/8`（合计 = 100）。**色值是实测的，配比是你给的建议值** —— 页面文案已如实标注。

### 第 2 步：写数据

编辑 `build.py` 的【配置区】：

```python
WK, OUT, BRAND_NAME, BRAND_EN, BRAND, BRAND_D   # 路径 + 品牌字 + 强调色
VERSIONS = [ dict(no='壹', key='A', name='...', blocks=[(小标题, 正文), ...],
                  colors=[(名称, HEX, 占比, 卡面文字色)], note='...', tags='...'), ... ]
```

- `key` 必须与 `prep-assets.py` 的 `FILES` key 对齐（A/B/C）
- `blocks` 每段正文 **60~80 字**，排在 440.4px 宽的栏里正好 3 行
- `colors` 的 `卡面文字色`：深色卡用 `'FFFFFF'`，浅色卡用 `'1C1C16'`

### 第 3 步：出活并验收

```bash
python build.py
# 转 PDF（纯 ASCII 输出目录，避开中文路径坑）
soffice --headless --norestore -env:UserInstallation=file:///C:/temp/lo_bee \
        --convert-to pdf --outdir "C:/temp/out" "<OUT>"
# 查图片零变形（12 个图片形状，失配数必须 = 0）
python 04-知识沉淀/工具/probe-pptx.py "<OUT>"
```

## 三、硬规矩（都是踩过的）

| # | 规矩 | 踩坑记录 |
|---|---|---|
| 1 | **反白稿必须「双色互换」**：暗部 → 白，亮部 → 本版主色。**不可**把可见像素涂白 | 涂白 → 一坨无结构白剪影，门头/围裙/名片上全废 |
| 2 | **去背图必须裁透明边** | 原图自带大片透明边，不裁则内容只占框宽六成，多版并排大小不一 |
| 3 | **白底图去背用四角洪水填充**（thresh≈42），不可全局白转透明 | 全局转会吃掉白厨师服、牙齿、头巾 |
| 4 | **段落节奏**：正文 `lh=1.62`、段步进 120px、正文起 `yy+34` | 曾用 `lh=1.9` + 步进 119 → 段占 119.5，**段间距 −0.5px**，三段粘连成一坨 |
| 5 | **中文字体必须同时写 `a:ea`** | 只写 `font.name` 只影响拉丁字符，中文回退宋体 |
| 6 | **图片一律等比 contain**，绝不拉伸 | `picture()` 已封装 |
| 7 | **先量再改**：探针 + 像素扫描，目测不可信 | 读图返回的是**缩放预览**，在缩放图上量边界误差被系统性放大 |
| 8 | **命令退出码 0 ≠ 成功**：soffice/Chrome headless 都有"零产出"失败模式 | 收尾必 `ls` 数数量 + 看体积 |

## 四、微调点（直接改数值）

| 想要的效果 | 改哪里 |
|---|---|
| 展示台大小 | P1-P3 的 `rect(s, MX, 158, 560, 442, PLATE)` 与 `picture(...)` |
| 三段文字更松 | 段步进 `yy += 120`（注意末段底不能越过色彩区分隔线 630） |
| 色卡数量 | 现为 4 格；`cw = (CW - 3*20) / 4` 改 4 与 3 |
| 配比条 | 段宽 `< 72px` 时百分比自动省略 |
| 载体内容 | P5 段：`kA/kB/kC` 取自 `VERSIONS` 顺序，改索引即换版 |
| 版数 > 3 | P1-P3 / P4 自动随 `VERSIONS` 长度；**P5 载体仍假设 3 版**，需手改 |
