# VI 全案提案母版规范 v1.0

> 来源：5 本真实交付册 · 231 页 · 创梦餐饮品牌策划设计出品
> （三餐里 35 页 / 小耕班 51 页 / 摘山语 37 页 / 蘑菇围炉 49 页 / 鸽子官 59 页）
> 方法：PPTX 解包 → 原图提取 → 视觉精读 → 像素级版面度量

---

## 0. 先说三个反常识的结论

**① 这 5 本册子用的其实是同一套母版。**
五本画布尺寸、页眉线位置、章节页徽章结构、尾页版式全部高度一致。像素度量给出的页眉分隔线位置：三餐里 12.9%、小耕班 12.5%、摘山语 12.9%、鸽子官 12.3%——**跨册落在 12.3%–13.1% 的 0.8% 窄带内**。这不是巧合，是同一套设计体系的指纹。

**② 交付形态是"一页一图"的图册型 PPT，不是可编辑排版。**
每个 PPTX 里每页只有一张满幅设计稿（`x0% y0% w100% h100%`），PPT 自带的母版、版式全是 Office 默认值，**没有任何真实排版参数**。也就是说：**客户最终拿到的是"设计好的页"，不是"能改的模板"**。想改内容 = 重做那一页。

**③ 全套提案没有页码，模板 A 连页脚都没有。**
唯一的"定位系统"是页眉。这不是省略——是刻意的：**图册型提案靠视觉节奏自证位置，页码会破坏画面净度**。

## 1. 画布规格

| 项 | 值 |
|---|---|
| 比例 | **16:10**（858.9 × 540 pt，即 1.5905） |
| 设计稿分辨率 | 2066×1299 / 2338×1496 / 2755×1732（≥2000px 长边） |
| 出 PDF | 必须锁 `@page` 为画布尺寸，否则落 Letter 白边 |

> 注意：**不是 16:9**。用 16:9 的模板直接套，整页比例会歪。

---

## 2. 几何常量（可直接抄进 CSS）

以页高 100% 为基准：

| 元素 | 位置 | 说明 |
|---|---|---|
| 页眉文字顶端 | **11.4%** | 模板 A |
| **页眉分隔线** | **12.9%**（模板 A）/ **13.1%**（模板 B） | 全册统一，垂直居中对齐于页眉文字 |
| 页眉带高度 | ≈ **15%** | 线在带内垂直居中 |
| 内容区 | **15% → 100%**，内容**垂直居中** | 不强制撑满 |
| 左右边距 | **11.0% / 10.8%**（模板 A）· **6.2% / 6.2%**（模板 B） | A 疏朗、B 饱满 |
| 章节页内容中心 | **49.9% , 49.5%** | 精确画面正中 |

**页眉横线的两种画法（这是两套模板最直观的区别）：**

- **模板 A**：线在左标签与右英文**之间**，两端各留 25–30px 空隙
- **模板 B**：线从左标签右侧**一路贯穿到画布右边缘**

## 3. 两套模板

### 模板 A ——「徽章式」（4/5 本在用：三餐里 / 小耕班 / 摘山语 / 鸽子官）

```
页眉： [粗黑标签文字] ──────────────── [品牌英文]
        11.4% 起                          右对齐
        线在 12.9%，两端留隙
页脚： 无
```

### 模板 B ——「工作室式」（蘑菇围炉）

```
页眉： [小logo图标 + 品牌英文斜体] ─────────────────────────────→ 贯穿到右边缘
                                    [右上：栏目名 LOGO BRAND DESIGN]

页脚： [左下：椭圆线框徽章]                    [右下：两行右对齐英文小字]
        约 93% 处
```

## 5. 内容页的 8 种子版式（图文排布词典）

| 子版式 | 结构 | 适用 |
|---|---|---|
| ① 单件居中 | 单件图形居中，周围大留白 | Logo 展示、单件物料 |
| ② 多件横排 | 2–4 件等分并排 | 组合对比、系列展示 |
| ③ 网格阵列 | 2×2 / 3×2 / 4×2 等分网格 | 图标库、辅助图形、提示牌 |
| ④ 左右分栏 | 图 \| 文（50/50 或 60/40） | 图形释义、字体规范、图文论证 |
| ⑤ 满幅大图 | 全幅实拍/物料图铺满 | 空间展示、门头、广告 |
| ⑥ 卡片挂标 | 每张图上/下挂「品类名 + 一句话」标签条 | 菜品、产品线 |
| ⑦ 数据可视化 | 数字大字 + 条块 / 连线 / 金字塔 | 品牌信任状、卖点数字化 |
| ⑧ 规范展示 | 色卡条 / 字重阶 / 网格制图 / 明度阶 | 色彩系统、字体系统、制图规范 |

## 6. 色彩使用逻辑（五本册子的共同铁律）

| 角色 | 色值样本 | 用在哪 |
|---|---|---|
| **白 `#FFFFFF`** | 每本都是占比第一 | **所有常规内容页默认底** |
| **暖白/米白 `#F2EEE3` `#F3F0E9` `#F3EFE4` `#F7F4EF`** | 次高频 | 物料展示页——比纯白更暖、更"纸感" |
| **品牌主色** | 三餐里 `#4BCB04` / 小耕班 `#DE6E3C` / 摘山语 `#E6212A` / 蘑菇围炉 `#EA502C` / 鸽子官 `#EC6722` | **只出现在**：封面、章节页、宣言页、尾页 |
| **暗底 `#1D191A` `#342C2A` `#525451`** | 少量 | 空间氛围、灯光效果、重点价格页 |

**一句话逻辑**：`白 = 内容` → `暖白 = 物料` → `主色 = 章节骨架` → `暗底 = 氛围高光`。
主色是**节拍器**，不是背景板——它出现即代表"翻章了"。

## 7. 这条母版链的工作流

```
图片素材（设计稿）
      ↓
按页型归位：封面 / 序言 / 宣言 / 速览 / 章节 / 内容 / 尾页
      ↓
内容页选子版式（①②③…⑧）
      ↓
套母版骨架（页眉 + 留白 + 垂直居中）
      ↓
导出 PDF（16:10 + @page 锁尺寸）
```

> 落到本项目：`html-ppt` 产线负责承载，但**页眉页脚必须按本规范手写**——`html-ppt` 自带版式没有这套页眉。

---

## 8. 铁律

1. **不设页码**（模板 A 连页脚都没有）
2. **页眉线位置全册锁定**，不因页面内容多少而浮动
3. **章节页必须满版主色**，是唯一的"翻章"信号
4. **内容页不撑满**，垂直居中，宁可留白
5. **画布 16:10，不是 16:9**
6. **Logo/标识类仍走矢量精绘**，母版只负责"摆"，不负责"生"
