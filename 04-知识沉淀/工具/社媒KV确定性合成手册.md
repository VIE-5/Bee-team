# 社媒 KV 确定性合成手册

> 用途：把「AI 生图」与「中文 / Logo」彻底分开 —— **生图只出无字画面，中文与标识全部用代码合成**。
> 解决两个硬伤：模型写中文必出伪字；模型重绘 Logo 必走形。
> 首单跑通：土蚝小院 —— 抖音竖版主 KV（1080×1920）＋ 横版主 KV（1920×1080）＋ 品牌视觉规范页（A4），2026-09-19。
> 工具：`Pillow`（隔离环境）+ 本机字体。

---

## 一、管线（五步，别跳）

```
① 生图：无字画面（prompt 内明写 no text / no logo / no watermark）
② 定位水印：脚本扫源图右下象限的「近中性亮像素」→ 得到水印 bbox
③ 物理切除：裁掉源图水印所在高度的全部像素（不要靠覆盖，覆盖会留鬼影）
④ 确定性排版：PIL 贴官方 Logo（按墨迹 bbox 定位）+ 中文排版 + 色值取品牌规范
⑤ 自检：像素级核对（净空、安全带、水印残留、产品可见度）→ 出成品
```

## 二、六条铁律（全是踩出来的）

1. **禁止用实色文字带横盖画面中下段。**
   实拍画面的产品通常就在下三分之一，一条 830–1440 的实色带会把菜整段盖掉 —— 餐饮 KV 没有菜＝废稿。
   **正解**：文字直接落在画面自带的浅色留白上（墙面/天空）；画面无留白时，改「上图下字」分区版式。

2. **水印靠"切"不靠"盖"，但"怎么找到它"要看它压在什么底上。**
   该生图通道默认右下角带 AI 水印，prompt 关不掉。分两种情形：

   | 情形 | 检测法 | 原因 |
   |---|---|---|
   | 水印压在**亮底**（如岩米实色带）上 | 阈值扫「近中性亮像素」可得 bbox | 白字与亮底仍有对比，簇状分布明显 |
   | 水印压在**暗/虚化底**上 | ⛔ **阈值法失效**，必须改用**几何切除 + 废弃条带反证** | 水印半透明 → 叠在暗带上后 min(channel) 到不了阈值；同时**亮墙高光会越阈值造成大片假阳性**（本例墙均色 196/185/173，高光 >205，全画扫出 3789 个假水印像素） |

   **双向复核（缺一不可）**：
   - 正向：在**裁掉的条带**里应确实扫到水印 bbox → 证明"我们量对了位置"；
   - 反向：在**保留区**按 20×20 块统计"高密度近白中性块"→ 应为 0（水印是成片文字，面积成块）。
   横版实例：废弃条带（源 x1346–1536）扫出 bbox `[1415,963]–[1525,1013]` → 水印确在此带，
   故裁到 x=1380 一刀切净（留 35px 余量）。

3. **横版「左文右景」的版面定式（1920×1080）。**
   左栏 **486–500px 岩米实色纸底** 承 Logo + 副标 + 主口号（三行三字），右侧照片满幅铺满余宽。
   **左栏必须做成独立图层再整体贴回画布** —— 否则 Logo PNG 的透明边缘有可能污染照片区。
   裁切照片时优先保两件事：**① 最右产品完整；② 顺带切掉虚化前景带与水印**（往往一刀两得）。
   定裁切边界的量测顺序：先扫"最右侧近中性亮像素的 max x"（产品的物理边界，本例 1339），
   再扫"右侧连续暗带起点"（虚化带边界）→ 取二者之间。
   ⚠️ 只看整图缩略图会把"产品被切边"当成正常出血，**必须量像素**。

4. **Logo 落位按"墨迹包围盒"算，不按文件尺寸算。**
   官方 Logo 文件四周留白往往不对等（本例左右 449/437、上下 80/141）。缩放后用墨迹 bbox 反推贴图坐标，
   才能保证 **视觉尺寸一致 + 净空 ≥ 墨迹高 25%**。

5. **缩放预览会骗人。**
   读图工具返回的是缩放图，1920 高会被压到约 1080。判断"有没有压住/撞上"必须**裁 1:1 局部放大**再看，
   否则会误判（本例缩略图上"副标像被 Logo 尾巴压住"，1:1 一看间隙很干净）。

6. **栏内文字一律"按宽自动收字号"，禁止用切片凑宽度。**
   写规范页/卡片时用 `s[:16]`、`s[:19]` 硬截断，会产出"……不作正文"这类**断句残句**（本轮实际发生）。
   正解：写 `Tfit()` —— 给定栏宽，逐档降字号直到放得下：

## 四、代码骨架（Pillow）

```python
# 1) 水印定位
def wm_scan(pix, x0, x1, y0, y1, bright=150, neutral=25):
    b = [x1, y1, -1, -1]
    for y in range(y0, y1):
        for x in range(x0, x1):
            r, g, bl = pix[x, y]
            if min(r, g, bl) > bright and (max(r, g, bl) - min(r, g, bl)) < neutral:
                b[0] = min(b[0], x); b[1] = min(b[1], y)
                b[2] = max(b[2], x); b[3] = max(b[3], y)
    return b if b[2] > 0 else None      # None = 未检出 → 别改阈值乱试，走「几何切除+反证」

# 2) 裁掉水印 + 铺满画布
src = src.crop((0, 0, W, wm[1] - 146))          # 留足余量
img = src.resize((CW, int(src.height * CW / W)), Image.LANCZOS)

# 3) Logo 按墨迹 bbox 定位（官方文件绝不重绘）
ls = TARGET_INK_W / ink_w
lg = lg.resize((int(lg.width*ls), int(lg.height*ls)), Image.LANCZOS)
lx = int(CX - (ink_x0*ls + TARGET_INK_W/2))
ly = int(INK_TOP - ink_y0*ls)
cv.paste(lg, (lx, ly), lg)                       # 保留 alpha

# 4) 中文字体（可变字重）
f = ImageFont.truetype(r"C:/Windows/Fonts/NotoSansSC-VF.ttf", 100)
f.set_variation_by_axes([900])                    # Heavy

# 5) 带字距的文本（可变字体 set_variation_by_axes 对字距无效，必须逐字推进）
def T(dr, x, y, s, f, fill, anchor="lm", tr=0):
    if tr == 0:
        dr.text((x, y), s, font=f, fill=fill, anchor=anchor); return
    w = sum(f.getlength(c) for c in s) + tr*(len(s)-1)
    cx = x - w/2 if anchor[0] == "m" else x       # m=以 x 为中线，l=以 x 为左缘
    for c in s:
        dr.text((cx, y), c, font=f, fill=fill, anchor="l"+anchor[1])
        cx += f.getlength(c) + tr

# 6) 按栏宽自动收字号（规范页/卡片用，禁止切片凑宽度）
def Tfit(dr, x, y, s, name, size, weight, fill, maxw, floor=11):
    while size > floor:
        f = font(name, size, weight)
        if tw(s, f) <= maxw: break
        size -= 1
    T(dr, x, y, s, f, fill); return size
```

## 六、出厂自检清单

- [ ] Logo 净空框顶 ≥ 安全带顶（如 130）
- [ ] Logo 墨迹尺寸与居中位置符合规格
- [ ] **水印双向复核**：废弃条带内扫到水印 bbox ＋ 保留区高密度近白中性块 = 0
- [ ] 产品带色彩种类 > 40（证明画面没被实色盖住）
- [ ] **产品边界未被切边**：实测最右/最下产品像素坐标 vs 画布边界
- [ ] 全部文字 y < 安全带底
- [ ] 主口号逐字一致（含标点）
- [ ] 画面内红色统一（Logo 自带红除外）
- [ ] 左栏底色抽样 = 品牌基底精确值（如 `(231,220,199)`）

## 七、规范页（一页制 · 本机渲染不耗额度）

规格页是**生产合同**，不是宣传页 —— 只写已定版事实，不写"建议""可选"。定式：

| 段 | 内容 |
|---|---|
| 页眉 | 品牌名（宋 Bold）+ 英文标（松柏绿带字距）+ 朱砂红规线 + 版本/日期/依据 |
| 01 Logo | 左：官方 Logo + **虚线净空框**；右：官方文件 / 最小尺寸 / 净空 / 允许变体 / 禁止处理 / 已知限制 |
| 02 色彩 | 色卡网格（色块 + 色名 + HEX + 角色 + 用途），最后一格放「用色规则」 |
| 03 字体 | 每套一张卡：组名 + 字体全名 + 真实样张 + 用途 + 授权 |
| 04 安全区 | 缩略示意图（色带区划）+ 数值行表 + **构图铁律**高亮卡 |
| 05 禁用 | 清单卡 |

工程要点：
- **逻辑单位设计 + S 倍超采样**：以 1600×2880（A4 比例）设计，`S=2` 输出 3200×5760（≈385dpi 可印）；
  所有坐标/字号统一过 `sc()`，改动只动逻辑值。
- **色卡里的 HEX 别用 Consolas** —— 它的零带斜杠，`#2D301B` 会被看成 `#2D3Ø1B`；换 Noto Sans 正常。
- **分区底色另设一个色（基底提亮）**，并在页上标注"非色板色"，避免读者误当品牌色。
- 交付前必须**逐段 1:1 裁片核对**（尤其长句右边界与卡片底边）。
