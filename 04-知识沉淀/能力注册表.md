# 能力注册表

> 蜂王拆完 DAG 后，为每个任务节点匹配执行方时查这张表。**随使用持续补充。**

## 使用规则

1. 按「任务特征」找最匹配的类别 → 直接用对应能力；
2. 无匹配 → 判断该路由给哪只工蜂，或标注【待路由】由蜂王自己处理；
3. 发现好用的组合 / 踩过的坑 → 追加到文末，越用越准。

## 四、承接边界（蜂群现在能接什么）

### ✅ 稳定接单（有专属工蜂 + 技能已验证）

| 任务类型 | 主责蜂 | 典型场景 |
|---|---|---|
| 资料调研 / 竞品分析 | W1 | 找同行案例、政策、市场数据 |
| 网页抓取 / 公众号采集 | W1 | 批量取文章标题与链接 |
| PPT 提案 / 方案册 | W2 | 品牌提案、汇报材料 |
| Word 文档 / 报告 | W2 | 方案书、综述、脚本 |
| Excel 表格 / 数据整理 | W2 | 清单、台账、对比表 |
| 生图 / 修图 / 去水印 | W3 | 主视觉、配图、素材净化 |
| 质量审查 / 事实核查 | W4 | 交付前把关、数据打假 |

### ⚠️ 有条件接单（能做，但有前提或质量风险）

| 任务类型 | 前提 / 风险 |
|---|---|
| 视频 · 3D · 模板特效 | 时长与分辨率受工具限制，需先小样验证 |
| **代码 / 应用开发** | **目前无专属工蜂**，暂由蜂王兼，建议补编 W5 工程蜂 |
| 品牌延展 · 周边 mockup | 依赖 brand-extension CLI，需装好连接器 |
| 图片内含精准文字 | 生成模型对文字最易翻车，建议后期排版叠加而非直出 |
| 需登录或付费的系统 | 需主人提供凭据或授权，蜂王不代持账号 |
| 对外发布 / 定时任务 | 平台支持，但发布动作须主人点头；定时任务需主人先设定规则 |

### ❌ 接不了

- 线下真实世界的操作（跑腿、打电话、当面交付）
- 代持账号密码等敏感凭据
- 自动调起专家中心的领域专家（需主人手动切换）
- 常驻后台持续监控（工蜂跑完即散，无常驻进程）

## 五、任务规模上限（超过就该拆阶段）

| 维度 | 建议上限 | 超了怎么办 |
|---|---|---|
| 单任务工单节点数 | ≤ 8 个 | 拆成多个阶段，分批次跑 |
| 同时并行工蜂 | 3-4 只 | 再多样本会互相污染，改串行接力 |
| 单次会话时长 | 尽量一单跑完 | 跨会话靠任务图续命，开工先读档案 |
| 单文件体积 | < 50MB 入库 | 超过走资产清单，不进 Git |

## 七、已验证的好组合

**组合 1 · 品牌 logo 设计落地**（2026-09-11 梅湖小院，首单实跑）
```
用户基础信息（名称/城市/人均/面积/风格/主打品）
  → W2 品牌策略分析（定位 · 客群 · 调性关键词 · 设计禁区）
  → W2 三套差异化设计方向（理念/符号/配色/字体）
  → W3 生图（每方向 1 张基准图，prompt 需强约束 no text/watermark）
  → 【必做】水印裁切补偿（工具：04-知识沉淀/工具/clean_logo.py）
  → W3 逐张目视复核
  → W4 六项清单 + 工种专项验收
  → 交付报告（含字体排版建议 + 商标风险提示）
```
**关键经验**：
- 策略阶段产出的「设计禁区」（忌高冷/繁复/撞脸）是后续选图的硬标准，必须有
- 中文字标**不要交给 AI 直出**，图形标 + 开源字体排版建议的组合更可靠
- 生图 prompt 必带：`no text, no letters, no watermark, no signature, no mockup, no 3D`
