# 能力注册表

> 蜂王拆完 DAG 后，为每个任务节点匹配执行方时查这张表。**随使用持续补充。**

## 使用规则

1. 按「任务特征」找最匹配的类别 → 直接用对应能力；
2. 无匹配 → 判断该路由给哪只工蜂，或标注【待路由】由蜂王自己处理；
3. 发现好用的组合 / 踩过的坑 → 追加到文末，越用越准。

## 三、已知的平台边界

| 事项 | 说明 |
|---|---|
| 多 agent 独立团队 | ❌ 本次环境未开放 TeamCreate，工蜂靠角色卡 + 文件协作实现 |
| 专家中心 | ⚠️ 需主人手动切换，蜂王不能自动拉起 |
| 子 agent 类型 | 仅 general-purpose / Explore / Plan / sheet-agent / doc-\* 系列可选 |
| 工蜂长驻 | ❌ 子 agent 跑完即散，记忆靠蜂巢文件延续 |
