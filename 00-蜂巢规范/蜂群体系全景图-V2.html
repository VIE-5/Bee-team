06

排版铁律 R1–R16

LAYOUT LAWS

从 R1–R6 起步，经碗香 / 土蚝 / 蒸馏册多轮实战扩到 R16。每一条都对应一次真实事故，不是纸上规范。

R1满幅层写死 height:100%，绝不只靠 inset:0（transform 祖先会让拉伸解析失效）
R2内容容器必须显式 left/right:var(--mx)，否则继承 padding 压住边款
R3不给 .slide 写 padding:0；满幅请用负 margin
R4锁 @page{size:Wpx Hpx;margin:0}，导出后核对 MediaBox
R5疑难上探针（probe-box.js），别读 CSS 猜
R6小体积 PNG ≠ 空白页（墨底满幅 20–40KB 属正常）
R7固定画布下尺寸一律硬编码 px，百分比在 flex 推导高度里会被拒解
R8print 里补 overflow:hidden，否则 PDF 页数 = slide 数 + 1
R9「看起来不对」也先量再改，且先确认读的图有没有被缩放
R10批量替换脚本收尾双向复核（数新标记 + 数旧标记）
R11量 DOM 前先摘祖先 transform，否则测量值偏大
R12页面容器 class 必须独立命名空间 pg-*（撞车 → 打印多一页 / 截图全同）
R13「一对多」登记表键必须带归属维度（如 (篇,节号)）
R14目录 / 索引类交付必做逐行回验，输出「错行数 / 总行数」
R15版式一改，实测尺寸缓存立即作废 → 必重跑 --measure 再重建
R16删页 / 改名 / 调序后，页码基准与署名落点同步重算并回验
贯穿全条的根因：`overflow:hidden` 会静默裁掉超出内容——「内容是否完整」必须单独量，工具本身也要双向验证（正式产物 PASS + 坏样本 FAIL）。
